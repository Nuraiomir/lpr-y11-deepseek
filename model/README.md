# Модель детектора

Сюда надо положить `best11n_512.onnx`, экспортированную YOLO11n.

    cp ~/nurai_gpu/model/best11n_512.onnx model/

В репозитории её нет нарочно: в этом репозитории модель обучается, а значит
меняется, и каждая версия весов в истории git раздувала бы её без пользы.
Обученные веса версионируются отдельно, а в образ модель кладётся при сборке.

Путь, по которому сервис её ищет, задаётся переменной `MODEL_PATH`. Принимает
и файл, и каталог с единственным `.onnx` внутри: в кластере каталог
подкладывает init-контейнер, локально удобнее указать файл.

## Чего здесь нет

Весов распознавателя символов. В этом репозитории символы читает модель в
кластере через AI Gateway, и локальных весов у неё нет вовсе: сервис
обращается к ней по сети.
