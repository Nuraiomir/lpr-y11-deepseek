# Зависимости ОБУЧЕНИЯ. В окружении сервиса их нет и быть не должно.
#
# Главная причина разделения не размер, а лицензия. Ultralytics под AGPL-3.0,
# и это накладывает обязательства на всё, с чем она слинкована в работающем
# продукте. Здесь она не работает в продукте: она обучает модель и
# экспортирует её в .onnx, а сервис грузит этот файл через ONNX Runtime и об
# Ultralytics ничего не знает. Граница проходит ровно по этой папке, и
# переносить эти пакеты в pyproject.toml сервиса нельзя.
#
# Вторая причина: torch с поддержкой CUDA это несколько гигабайт, которым
# нечего делать в образе сервиса, работающего на процессоре.
#
# Ставить в отдельное окружение:
#     python3.12 -m venv .venv_train
#     .venv_train/bin/pip install -r training/requirements.txt

# пришитая версия сломает обучение на другой машине молча.
